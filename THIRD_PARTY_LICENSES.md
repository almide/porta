# Third-party licenses

Rust crates compiled into the `porta` binary, as resolved for Linux (x86-64, arm64) and macOS (arm64).
Generated by `scripts/third_party_licenses.py`; each crate's full licence text is in its source
package on crates.io. Where a crate offers a choice, porta takes it under the permissive option
(MIT or Apache-2.0; BSD-3-Clause for crates also offered under GPL-2.0).

Not compiled in, but loaded at run time on Linux: the C library (glibc, LGPL-2.1+), dynamically
linked from the host or image. TLS is rustls; porta links no OpenSSL.
Almide, the compiler porta is written in, is not part of the binary beyond its generated code.
